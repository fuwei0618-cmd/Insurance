# 保險手冊

iPad 用的保險手冊 PWA。首頁是「保險手冊專題」：第一章人生願景與風險觀念、第二章保障與工具、第三章保險規劃三步驟，加上資料庫（疾病排名與花費）。

- 首頁 `index.html` 由專題手冊自動產生，`docs/` 放商品 DM 與條款圖（`gNN.webp` 是專題頁用的合併頁）。
- 舊版投影片手冊搬到 `/old/`，講稿仍以密碼加密，原始碼中沒有明文。
- `/topics/` 會自動轉到首頁。
- 本站設定 noindex，不會被搜尋引擎收錄；repo 裡沒有任何客戶資料。

## 工作手冊（`crm/`）

自己用的業務工作手冊：案件、掃描文件、個資遮罩、理賠參考、SOP、快查、話術範本。

- 網址：`/Insurance/crm/`，保險手冊本身不會連到這裡。
- 資料用自己設定的密碼加密後，存在 OneDrive › 應用程式 › Work › Cathay。這個 repo 裡沒有任何客戶資料。
- 用戶端識別碼填在 `crm/config.js`。
- 網址加 `?test` 是測試模式（資料只存在那台裝置），加 `?real` 關閉。
